# Nombre del Proyecto: Momento-1

## Descripción del Problema
Este proyecto surge de la necesidad de organizar el código de una aplicación web, evitando tener todo el contenido en un solo archivo. Se buscaba aplicar la lógica de componentes de React para hacer que la interfaz sea más fácil de gestionar y escalar a medida que el proyecto crezca.

## Tecnologías Utilizadas
* React
* Vite
* NPM
* CSS3
